# Soccer Icons & Logo Resources

## Free Icon Libraries (easy to use in HTML/CSS)

- **[Font Awesome](https://fontawesome.com)** — has a soccer ball icon (`fa-futbol`), free tier available
- **[Google Material Icons](https://fonts.google.com/icons)** — clean flat icons, free
- **[Flaticon](https://www.flaticon.com)** — thousands of soccer-specific icons (PNG/SVG), free with attribution
- **[SVG Repo](https://www.svgrepo.com)** — search "soccer", download clean SVGs, fully free

## Club / Federation Logos

- **[Wikimedia Commons](https://commons.wikimedia.org)** — official club crests in SVG format
- **[Sports DB](https://www.thesportsdb.com)** — team logos via API, free for non-commercial

## Quick Drop-in: Font Awesome

Add to `<head>`:
```html
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css"/>
```

Usage:
```html
<i class="fa-regular fa-futbol"></i>
```
